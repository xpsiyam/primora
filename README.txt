PRIMORA KIT — চালু করার নিয়ম
==============================

১) প্রথমবার শুধু একবার: Python ইনস্টল করুন  (https://www.python.org/downloads/)
   ইনস্টলের সময় "Add Python to PATH" টিক দিতে ভুলবেন না।

২) এই ফোল্ডারের ভেতর  run.bat  ফাইলে ডাবল ক্লিক করুন।
   (প্রথমবার Flask ইনস্টল হতে একটু সময় লাগবে।)
   ব্রাউজারে নিজে থেকে ওয়েবসাইট খুলে যাবে:  http://127.0.0.1:5000

   কমান্ড দিয়ে চালাতে চাইলে (CMD এ এই ফোল্ডারে গিয়ে):
       pip install -r requirements.txt
       python app.py

৩) ওয়েবসাইট বন্ধ করতে কালো উইন্ডোতে  Ctrl + C  চাপুন।

Gmail ও Telegram এ অর্ডারের খবর পাওয়া
----------------------------------------
অ্যাডমিনে ঢুকে "🔔 নোটিফিকেশন সেটিংস" খুলুন।

    ২. একই জায়গায় "App passwords" থেকে একটি পাসওয়ার্ড বানান (১৬ অক্ষর)।
    ৩. সেটি "Gmail App Password" ঘরে বসিয়ে সেভ করুন।

  Telegram:
    ফোন নম্বর (01843010908) দিয়ে Telegram-এ সরাসরি মেসেজ পাঠানো যায় না, তাই একটি বট লাগে।
    ১. Telegram এ @BotFather খুলে /newbot লিখুন → সে একটি Token দেবে।
    ২. আপনার নতুন বটটি খুলে Start চাপুন।
    ৩. সেটিংসে Token বসিয়ে "Chat ID খুঁজুন" চাপুন → "এটি ব্যবহার করুন" → সেভ।

    ৪. "টেস্ট নোটিফিকেশন" চেপে দেখুন মেসেজ আসছে কিনা।

  Token ও App Password কাউকে দেবেন না, চ্যাটেও পেস্ট করবেন না।

ব্যাকআপ
--------
অ্যাডমিনে "💾 ডাটাবেজ ব্যাকআপ" চাপলে সব অর্ডারসহ ডাটাবেজ ডাউনলোড হবে।
সপ্তাহে একবার নিয়ে রাখুন। ডাটাবেজ ফাইল: primora.db (এই ফোল্ডারেই থাকে)।


ফোল্ডারের ফাইলগুলো
-------------------
  run.bat            চালু করার ফাইল (ডাবল ক্লিক)
  app.py             ওয়েবসাইটের মূল প্রোগ্রাম
  database.py        ডাটাবেজ
  seed_data.py       প্রথমবারের কম্বো/পণ্য
  notify.py          Gmail + Telegram
  translations.py    ইংরেজি ভার্সনের লেখা
  templates/         ওয়েবসাইটের পেজগুলো
  static/            ছবি ও ডিজাইন (css)
  test_app.py        অটোমেটিক টেস্ট (python test_app.py)


অনলাইনে হোস্ট করলে
-------------------
  - Python সাপোর্ট করে এমন হোস্টিং লাগবে (PythonAnywhere paid, VPS ইত্যাদি)। XAMPP এ Flask চলে না।
  - হোস্টিংয়ে ফাইল স্থায়ীভাবে থাকতে হবে (না হলে primora.db এর অর্ডার হারাতে পারে)।
  - HTTPS চালু হলে  COOKIE_SECURE=1  এবং  FLASK_SECRET_KEY=লম্বা-র‍্যান্ডম-লেখা  সেট করুন।
